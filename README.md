# field-data-quality-kenya

A data quality pipeline for agricultural field survey data from Kenya: the kind of farmer registrations, GPS points and farm boundary polygons that an agri-insurance company collects through ODK. It flags problems such as missing or duplicate records, GPS points outside Kenya or far from their declared location, invalid or self-intersecting polygons, implausible farm sizes and overlapping farms, then produces a clean dataset, a summary report and an interactive map for reviewing the flagged records.

## Data

> **The farmer data is simulated.** No real farmers, names, national IDs, phone numbers or farm locations are included. The records are generated by [scripts/generate_survey.py](scripts/generate_survey.py) with a fixed seed, and about 10% of them contain deliberately planted errors. The planted errors are listed in `data/raw/planted_errors.csv` so the pipeline's results can be scored against a known answer.

| File | Contents |
|---|---|
| `data/raw/kenya_counties.geojson` | Kenya's 47 county boundaries from [geoBoundaries](https://www.geoboundaries.org) (gbOpen, ADM1, public domain). Source details are in `kenya_counties.source.json`. |
| `data/raw/farmer_registrations.csv` | 600 simulated registrations in Nakuru, Kakamega, Bungoma, Meru and Uasin Gishu. |
| `data/raw/farm_boundaries.geojson` | One farm polygon per `farmer_id`. |
| `data/raw/planted_errors.csv` | Ground truth: `farmer_id`, `error_type`, `related_farmer_id`, `details`. |

To rebuild them:

```powershell
python scripts/download_boundaries.py
python scripts/generate_survey.py --seed 42
```
